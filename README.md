# Shreya Harish Yagain | Portfolio

A dual-mode portfolio with two personalities in one site: an **engineering side** styled like a green oscilloscope terminal, and an **artist side** styled like a cream sketchbook. A flip button at the top right switches between them.

**Live site:** https://shreya-portfolio-mu.vercel.app


## Features

### Engineering side
- Animated boot sequence and an oscilloscope-style hero with a live signal trace
- Projects grid with GitHub links and project media
- Interactive skills circuit board: hover (or tap) a component to see the skills it represents
- Experience, leadership and activities, and certificates sections
- Downloadable resume
- Retro CRT grain and scanline texture, plus a custom crosshair cursor

### Artist side
- Editorial hero with a transparent cutout portrait and hand-drawn underlines
- About section with a scrapbook-style collage of notes and polaroids
- Digital lyric video showcase (click-to-load YouTube thumbnails with a modal player)
- Sketchbook gallery of 22 artworks with a lightbox
- Process, tools and mediums, and a "currently exploring" board
- Commissions section with availability status, how-it-works steps and a prefilled email request
- Custom pencil cursor
